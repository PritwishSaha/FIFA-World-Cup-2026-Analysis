## 📌 Project Overview

The **FIFA World Cup 2026 Team Analysis Dashboard** is an interactive Power BI project that analyzes the qualified teams participating in the FIFA World Cup 2026.

The dataset was downloaded from **Kaggle**, cleaned using **Microsoft Excel**, and transformed into an interactive **Power BI Dashboard** to provide insights into team performance, FIFA rankings, market value, previous World Cup achievements, and continental representation.
