🌍 Project Overview

The FIFA World Cup 2026 Team Analysis Dashboard is an interactive Power BI Business Intelligence project designed to analyze the teams participating in the 2026 FIFA World Cup.

The project transforms raw football data into meaningful visual insights covering:

- ⚽ Team performance
- 📊 FIFA ranking points
- 💰 Team market value
- 🏆 Previous World Cup achievements
- 🌎 Continental representation
- 📈 Performance comparison between nations

The dataset was sourced from Kaggle, cleaned and prepared using Microsoft Excel, and then transformed into an interactive Power BI dashboard.

«From raw football data → cleaned dataset → interactive insights.»
